# nsbaci
nsbaci (Nicolás Serrano BAsic Concurrency Interpreter) is a small development environment to learn concurrency. It is based on the jBACI application developed by Ben Ari

## User Guide

NSBACI has online documentation, both for developers and users. You can find both guides [here](https://nsbaci.nicolasserranogarcia.com).
