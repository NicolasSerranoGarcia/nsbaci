Installation notes

Windows

Windows may show a "Windows protected your PC" warning because the installer is not digitally signed. Click More info then Run anyway to proceed.

Linux

  1. Make the file executable: chmod +x nsbaci-*.AppImage
  2. Run it: ./nsbaci-*.AppImage

If you see a "FUSE not found" error, install it first:
sudo apt install libfuse2 (Debian/Ubuntu) or sudo dnf install fuse-libs (Fedora).

macOS

  1. Open the .dmg and drag nsbaci to Applications.
  2. On first launch, right-click the app and select Open to bypass Gatekeeper.
